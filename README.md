# RadNote

RadNote is a Chrome extension for radiology learners who want to turn selected source material into reviewable study assets while keeping source links and attribution visible.

## Official links

- Website: https://www.radnoteapp.com/
- Chrome Web Store: https://chromewebstore.google.com/detail/radnote-%E2%80%94-radiopaedia-to/albabcfkhabighccjjlcnegpkcimkggh

## Study workflow

A typical RadNote session is deliberately source-first:

1. Open the case, article, or source page being reviewed.
2. Select the teaching points worth revisiting.
3. Export Anki-ready notes, PDF study sheets, or case conference slides.
4. Keep the source URL and attribution attached to the output.

## Useful outputs

- Anki-ready review material for spaced repetition.
- PDF study sheets for compact review before rounds or exams.
- Case conference slides for teaching preparation.
- Source-linked notes that remain easier to audit later.

## Independent product boundary

RadNote is an independent study workflow tool. It is not presented as an official Radiopaedia product. It is designed for selected, reviewed study material rather than automatic bulk collection.
