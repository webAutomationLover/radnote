RadNote Install Notes

RadNote is a Chrome extension for radiology study workflows. It helps turn selected Radiopaedia articles and cases into Anki decks, PDF study sheets, and case conference slides while keeping source links and attribution visible in the export.

Install path

  1. Open the RadNote Chrome Web Store listing.
  2. Add the extension to Chrome and keep it enabled for study sessions.
  3. Open selected Radiopaedia material, review it, and export only the learning material you intend to study.
  4. Check each generated Anki, PDF, or slide export for the original source link and attribution before sharing or reviewing it.

RadNote is an independent study workflow tool. It is not an official Radiopaedia product. Users should review the source page and keep attribution visible.
