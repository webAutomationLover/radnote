RadNote FAQ

What is RadNote?

RadNote is a Chrome extension workflow for turning selected Radiopaedia articles and cases into reviewable study assets.

What can it export?

Common outputs include Anki decks, PDF study sheets, and case conference slide outlines.

Where can I install it?

Use the official RadNote Chrome Web Store listing.

Is RadNote official Radiopaedia software?

No. RadNote is an independent study workflow tool. It is not an official Radiopaedia product.
